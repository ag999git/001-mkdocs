    19.4 String indexing and immutability Strings in Python are an ordered collection of characters. "Ordered" means that it is a sequence of characters. In Python, the individual characters are accessed by their index, which starts from 0 and ends at one less than the length of the string. Thus, if the length of a string is n, then its index will be from 0 to n-1. (This is similar to C++). However, in Python, we can also access the individual characters of a string using negative indices as well. The last character in the string has a negative index of -1, and the first character (For a string of n characters) has an index of –n. The indexing applies to string variables as well as string literals. The other important characteristic of a string sequence is its immutability, which means you cannot change any character appearing at a particular index (position) of the string. This is clear from the following:

    # String immutability and indexing
myString = "Hello World!"
print(myString[0])  #'H'. Indexing starts at 0
print(myString[-1]) #'!'. Negative indexing starts from the end

    H
!

    19.5 Escape sequence In Python, inside a string literal (which begins with a single, double, or triple quote), a backslash, i.e., \ has the magical power of an "escape character". This means that a backslash isn't interpreted as a backslash, but as a signal that the next character is to be given a special interpretation.

    # Escape Sequences Demonstration Script
print("I want a Backslash: \\")  # Backslash character
print('It\'s a cold day!')  # Single quote inside string
print("He said, \"Good Morning\"")  # Double quotes inside string
print("Hello\nWorld!")  # New line between Hello and World
print("Hello\tWorld!")  # Tab space between Hello and World
print("First Line\rSecond Line")  # Carriage return
print("Column1\bColumn2")  # Backspace character
print("Unicode Character: \u03A9")  # Greek capital letter Omega (Ω)

    19.7 Traversing Strings: Iterating Through Characters Traversing a string means visiting each character in it, one by one, from the first index to the last. Since a string is a sequence with every character sitting at a known index, traversal lets you print characters individually, count them, search for specific ones, or apply logic to each one in turn — for example, counting vowels or checking for uppercase letters. In Python, this is typically done using either a for loop or a while loop. Method 1: Direct Character Iteration (The for Loop) The most common and clean way to traverse a string is by using a for loop. This pattern treats the string directly as an iterable sequence. Python automatically extracts each character, assignment-by-assignment, without requiring you to manually manage index numbers.

    msg = "Python"
# Iterating directly over the characters
for char in msg:
    print(char, end="-")
# Output: P-y-t-h-o-n-

    P-y-t-h-o-n-

    Method 2: Index-Based Iteration (The while Loop) Alternatively, you can traverse a string by combining its index sequence with a loop counter variable. This approach is highly useful when your application needs to know the exact position index of a character while processing it, or when you need to skip characters dynamically.

    msg = "Python"
index = 0
# Iterating using index boundaries
while index &lt; len(msg):
    print(f"Index {index}: {msg[index]}")
    index += 1
# Output: Index 0: P Index 1: y Index 2: t Index 3: h Index 4: o Index 5: n

    Index 0: P
Index 1: y
Index 2: t
Index 3: h
Index 4: o
Index 5: n

    Why This Matters for String Comparisons Understanding code points explains why string comparison results can sometimes surprise beginners. Let us look at two common rules: 1. Uppercase letters are "smaller" than lowercase letters: Because ord('A') is 65 and ord('a') is 97, evaluating 'A' < 'a' results in True. 2. Alphabetical comparison is strictly index-by-index: Python compares strings starting from index 0. If characters match, it moves to index 1, and so on, until it finds a difference.

    # Comparing case
print("Is 'Apple' &lt; 'apple'?", 'Apple' &lt; 'apple')  # Output: True (as 65 &lt; 97)

# Step-by-step comparison
# 'B' (66) is greater than 'A' (65), so Python stops immediately
print("Is 'Blue' greater than 'Apple'?", 'Blue' &gt; 'Apple')   # Output: True

    # Comparing strings in Python
print('boy'&lt;'girl')  # True. Alphabetic order
print('Boy'&lt;'boy')  # True. Uppercase before lowercase
print('Girl'&lt;'boy')  # True. Uppercase before lowercase so G before b

    1. Searching for Substrings: .find() The .find() method searches a string for a specified substring. If it finds the substring, it returns the index of its very first occurrence. If the substring is not found, it returns -1.

    19.13 Checking for Palindromes Algorithmic Execution Steps (Using Negative Indexing) - Step 1: Calculate the absolute length of the input string (n). - Step 2: Compute the comparison limit endpoint: "comp"=n//2.

    • Step 3: Initialize a loop tracking counter variable i=0.
    • Step 4: While i<"comp" , systematically extract and compare the forward position character at index i with its mirror negative index relative position at -(i + 1).
    • Step 5: Evaluate the match condition: If a pair mismatch is detected, terminate immediately and return False. If the pair matches, increment the loop counter (i=i+1) and check the next inner layer.
    • Step 6: If the loop exits naturally without hitting a mismatch, the string is verified as symmetrical. Return True. Python Implementation Script

    This implementation mirrors the exact tracking variables, conditional diamond checks, and counter increments defined in our algorithmic flowchart. The script (Using negative index) to check for a palindrome is given below:

    def is_palindrome(in_string):
    print(f"\nEvaluating Input String: '{in_string}'")
    n = len(in_string)  # Length of the input string
    comp = n // 2  # Number of comparisons needed (half the length of string)

    i = 0  # Initialize the loop counter for comparisons
    while i &lt; comp:  # Loop until we reach the midpoint of the string
        forward_char = in_string[i]  # Character from start of string
        backward_char = in_string[-(i + 1)]  # Character from end of string
        if forward_char != backward_char:  # Mismatch found, not a palindrome
            print(f"In iteration {i}: '{forward_char}' != '{backward_char}'")
            return False  # Return False immediately if a mismatch is found

        print(f" -&gt; Iteration {i}: '{forward_char}' matches '{backward_char}'")

        i = i + 1  # Increment the loop counter for the next comparison

    # 8. Executed if the loop finishes cleanly (No path taken)
    # Flowchart Block: Result = True
    return True

# Case 2: Invalid Palindrome (Mismatched central character)
print("Is racexar a palindrome?:", is_palindrome("racexar"))

    19.14 Method 2: Slicing and Direct Equality Comparison.

    An alternative, highly "Pythonic" strategy to check for a palindrome is to generate a reversed copy of the entire string in memory and compare it directly to the original using the equality operator (==).

    Rather than walking through index pairs using a loop, we leverage extended slicing with a negative step ([::-1]) to reverse the sequence in a single operational step. Algorithmic Execution Steps (Using String Reversal)

    • Step 1: Accept the input string (s).
    • Step 2: Generate a fully reversed copy of the string using the expression rev = s[::-1].

    • Step 3: Evaluate the conditional equality check (s == rev):

      • If the strings are identical (Yes), categorize the input as a Palindrome.
      • If the strings do not match (No), categorize it as Not a Palindrome.

    Python Implementation Script (Matching the Reversal Flowchart) This script perfectly mirrors the linear logic and direct equality branch of your second flowchart.

    # SCRIPT: PALINDROME VALIDATION ALGORITHM (STRING REVERSAL METHOD)
# This script checks for a palindrome by creating a mirrored copy of the input
# string using extended slicing and performing a direct equality comparison.

def check_palindrome_reversal(s):
    print(f"\nEvaluating Input String (s): '{s}'")


    # Creates a reversed copy of the string using a stride/step of -1
    rev = s[::-1]
    print(f" -&gt; Generated Reversed String (rev): '{rev}'")

    if s == rev:
        # Flowchart Block: Palindrome
        print(" -&gt; Decision: Strings match! Result = True")
        return "Palindrome"
    else:
        # Flowchart Block: Not Palindrome
        print(" -&gt; Decision: Strings mismatch! Result = False")
        return "Not Palindrome"

# Case 1: Valid Palindrome Match
result_1 = check_palindrome_reversal("level")
print(f"Is 'level' a palindrome? {result_1}")

# Case 2: Mismatched Case Sincerity (Python is case-sensitive!)
result_2 = check_palindrome_reversal("madams")
print(f"Is 'madams' a palindrome? {result_2}")
