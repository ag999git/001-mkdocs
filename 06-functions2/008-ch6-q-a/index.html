    1. In Python you may call a function by value or by reference. Explain.¶

    Answer¶

    • Call by Value (for immutable objects):
    • Immutable objects: int, float, str, tuple

    • Modifications inside the function do not affect the original value

    • Call by Reference (for mutable objects):

    • Mutable objects: list, dict, set
    • Changes inside the function affect the original object directly

    2. What is the difference between arguments and parameters?¶

    Answer¶

    • Parameters appear in the function definition
    • Arguments are values supplied during the function call

    Example: 

    def add(a, b):  # parameters
    return a + b

add(2, 3)       # arguments

    3. Why are lambda functions called anonymous functions?¶

    Answer¶

    • They have no name.

    • They are defined inline using:

    lambda x: x + 2

    4. If lambda has no return statement, how does it return a value?¶

    Answer¶

    • A lambda implicitly returns the value of its expression.

    5. Explain the 5 types of parameters in Python.¶

    Answer¶

    Positional-or-Keyword¶

    def f(a, b):
    pass

    Positional-Only (before /)¶

    def f(a, b, /, c):
    pass

    Keyword-Only (after *)¶

    def f(a, *, b, c):
    pass

    Var-Position (*args)¶

    def f(*args):
    print(args)

    Var-Keyword (**kwargs)¶

    def f(**kwargs):
    print(kwargs)

    7. Explain Python’s module search path.¶

    Answer¶

    Python looks for modules in this order:

    1. Current working directory

    2. Directories in sys.path

    3. PYTHONPATH environment variable

    4. Standard library directories

    5. Site-packages

    If not found → ModuleNotFoundError.

    19. Quadratic formula solver¶

    Answer¶

    import cmath

def quadratic(a, b, c):
    D = b*b - 4*a*c
    r1 = (-b + cmath.sqrt(D)) / (2*a)
    r2 = (-b - cmath.sqrt(D)) / (2*a)
    return r1, r2

    20. Trapezoidal rule numerical integration (Advance usage)¶

    b. This exercise requires knowledge of Trapezoidal rule of numerical integration. The value of a definite integral (ie the area under the function) can be found using numerical integration. One common method for this is the Trapezoidal rule given by:-

    \[ \text{Area} = \int_{a}^{b} f(x) \, dx \approx h \left( \frac{1}{2} (f(a) + f(b)) + \sum_{i=1}^{n-1} f(a + ih) \right) \quad \text{where } h = \frac{b-a}{n} \]

    Write a function which takes the following 4 parameters:- - function f - lower limit a - upper limit b - number of intervals n
    Also write a docstring for the function which says:- '''Calculates the definite integral of a function f(x), between the boundaries a, b, by dividing the area to n equal trapezoids/ strips''' A sample program which calculates

    \[ \int_{1}^{2} \left(\frac{1}{x}\right) dx \]

    is shown below. We know that:-

    \[ \int_{1}^{2} \left(\frac{1}{x}\right) dx = \ln(2) - \ln(1) = \ln(2) \]

    Answer¶

    from math import log

def trapez_integrate(f, a, b, n):
    """
    Calculates the numerical value of the definite integral of
    a function f(x) using the Trapezoidal Rule.

    Args:
        f (function): The function to integrate.
        a (float): The lower limit of integration.
        b (float): The upper limit of integration.
        n (int): The number of trapezoidal strips (intervals).

    Returns:
        float: The approximate area under the curve.
    """
    # 1. Calculate the width of each strip (h)
    h = (b - a) / n

    # 2. Initialize the area sum with the average of the endpoints (0.5 * f(a) + 0.5 * f(b))
    # This is equivalent to (1/2)*(f(a) + f(b)) in the formula.
    y_sum = (f(a) + f(b)) / 2

    # 3. Sum the function values at the intermediate points (f(a + i*h))
    # Iterate from i=1 up to i=n-1
    for i in range(1, n):
        x_i = a + i * h
        y_sum += f(x_i)

    # 4. Multiply the total sum by the strip width (h) to get the final area
    area = h * y_sum
    return area

# --- Application to the problem: Integral of 1/x from 1 to 2 ---

def f_x(x):
    """The function f(x) = 1/x"""
    if x == 0:
        raise ValueError("Function is undefined at x=0")
    return 1 / x

# Define parameters for the integral
a = 1.0  # Lower limit
b = 2.0  # Upper limit
n = 10000 # Number of strips (higher 'n' yields better accuracy)

# Calculate the area using the Trapezoidal Rule
area_approx = trapez_integrate(f_x, a, b, n)

# Calculate the exact analytical value for comparison
area_exact = log(2) 

print(f"--- Trapezoidal Rule for Integral of 1/x from {a} to {b} ---")
print(f"Number of strips (n): {n}")
print(f"Approximate Area (Trapezoidal): {area_approx:.10f}")
print(f"Exact Area (ln(2)):{area_exact:.10f}")
print(f"Difference:{abs(area_exact - area_approx):.10f}")
    Output

Approximate Area (Trapezoidal): 0.6931471812
Exact Area (ln(2)):            0.6931471806

    21. Compute ∫ sin(x) dx from 0 to π¶

    Answer:-¶

    The following Python program computes this integral using the Trapezoidal Rule with 10,000 strips to achieve high accuracy. The code defines a general trapez_integrate function, defines the integrand \(\sin(x)\), and then applies the numerical method.

    from math import sin, pi

def trapez_integrate(f, a, b, n):
    """
    Calculates the numerical value of the definite integral of
    a function f(x) using the Trapezoidal Rule.

    Args:
        f (function): The function to integrate.
        a (float): The lower limit of integration.
        b (float): The upper limit of integration.
        n (int): The number of trapezoidal strips (intervals).

    Returns:
        float: The approximate area under the curve.
    """
    # 1. Calculate the width of each strip (h)
    h = (b - a) / n

    # 2. Initialize the area sum with the average of the endpoints
    y_sum = (f(a) + f(b)) / 2

    # 3. Sum the function values at the intermediate points
    # Iterate from i=1 up to i=n-1
    for i in range(1, n):
        x_i = a + i * h
        y_sum += f(x_i)

    # 4. Multiply the total sum by the strip width (h) to get the final area
    area = h * y_sum
    return area

# --- Problem setup: Compute integral of sin(x) from 0 to pi ---

def f_sin(x):
    """The function to integrate: f(x) = sin(x)"""
    return sin(x)

# Define parameters for the integral
a = 0.0     # Lower limit
b = pi      # Upper limit
n = 10000   # Number of strips

# Calculate the area using the Trapezoidal Rule
area_approx = trapez_integrate(f_sin, a, b, n)
print(f"Approximate integral of sin(x) from {a} to {b} is: {area_approx}")

    def power_seq(seq):
    result = [[]]
    for x in seq:
        result += [subset + [x] for subset in result]
    return result

    34. Recursive multiplication (no * allowed)¶

    Answer¶

    def recursive_product(m, n):
    if m == 0 or n == 0:
        return 0
    if n > 0:
        return m + recursive_product(m, n-1)
    if n < 0:
        return -recursive_product(m, -n)

# TEST Function
print(recursive_product(20, 33))
print(recursive_product(-5, 10))
print(recursive_product(-5, -10))
