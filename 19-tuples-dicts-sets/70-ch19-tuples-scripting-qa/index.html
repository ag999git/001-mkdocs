    . Q1. Write a script to make a tuple containing just the number 5. Print its type. Then, make an empty tuple and print its type.

    # Step 1: Create a single-element tuple using a trailing comma
single_item = (5,)

# Step 2: Create an empty tuple container
empty_item = ()

# Step 3: Print the types to verify they are both tuples
print("Type of single_item:", type(single_item))
print("Type of empty_item:", type(empty_item))

"""
HOW PYTHON WORKS: Single-Item and Empty Tuples
- The Trailing Comma Rule: A single item inside parentheses like (5) is seen by Python as a regular math operation, evaluating to just an integer. 
- Adding a comma tells Python to explicitly create a tuple object.
"""

    Q2. Write a script that puts three values ("Data", 2026, True) into one tuple. Then, unpack those values into three separate variables and print them.

    # Step 1: Pack three different values into a single tuple variable
packed_data = "Data", 2026, True  # Commas create the tuple automatically

# Step 2: Unpack the tuple into three independent variables
label, year, flag = packed_data

# Step 3: Print the variables to verify the values split correctly
print("Label:", label)
print("Year:", year)
print("Flag:", flag)

"""
HOW PYTHON WORKS: Packing and Unpacking
- Tuple Packing: Listing items separated by commas groups them into a single tuple.
- Tuple Unpacking: Placing variables on the left side of the equals sign automatically assigns the tuple's items to those variables in order.
"""
    Q3. Write a script that shows you cannot change a tuple element. Try to change the first item of a tuple and print the error message. 
    # Step 1: Create a basic integer tuple
numbers = (10, 20, 30)

# Step 2: Try to modify an item and catch the error safely
try:
    # Attempting to overwrite the item at index position 0
    numbers[0] = 99
except TypeError as error:
    # Step 3: Print the error message generated by Python
    print("Python Error Message:", error)

"""
HOW PYTHON WORKS: The Immutability Rule
- Immutability means that once a tuple is created in memory, its contents cannot be changed, added to, or removed. 
- Attempting to overwrite an element triggers a TypeError automatically.
"""

"""
HOW PYTHON WORKS: Read-Only Tuple Operations
- Python provides safe, non-modifying operations for tuples like len(), .count(), and .index() to scan data without changing the original object.
"""

    Q5. Write a script that adds the number 40 to the end of the tuple (10, 20, 30) using the + operator. Print the tuple and its memory ID before and after the change.

    # Step 1: Create the initial tuple and check its memory ID
my_tuple = (10, 20, 30)
print("Original Tuple ID:", id(my_tuple))

# Step 2: Use concatenation to add a new item and reassign the variable

# Step 3: Print the new tuple values and the new memory ID
print("New Tuple Values:", my_tuple)
print("New Tuple ID:", id(my_tuple))

"""
HOW PYTHON WORKS: Reassignment vs. Mutation
- Because tuples are immutable, you cannot add items to the original object. 
- Using + combines two tuples and builds a completely new tuple object elsewhere in memory. 
- The variable name is simply reassigned to look at this new memory address.
"""

HOW PYTHON WORKS: Tuple Slicing Mechanics
- Slicing copies a portion of your data into a brand-new tuple object. 
- The original tuple remains completely safe and untouched in memory.
"""

    # Step 1: Define the unsorted starting tuple
unsorted_data = (3, 1, 4, 2)

# Step 2: Pass the tuple to the sorted function
result_data = sorted(unsorted_data)

# Step 3: Print the outputs to analyze the containers
print("Sorted Result:", result_data)
print("Type of Sorted Result:", type(result_data))
    HOW PYTHON WORKS EXPLANATION: • Line result_data = sorted(unsorted_data): Because tuples are strictly immutable, they do not have a built-in .sort() method. • To sort the elements, you must pass the tuple into the global sorted() function. This function reads the tuple items and returns the sorted values inside a brand-new mutable list container, leaving the original tuple completely safe and unchanged.

    Q17. Write a script to extract the number 3 out of the nested data tuple ((1, 2), (3, 4)) using index brackets.

nested_data = ((1, 2), (3, 4))

# Step 2: Use chained square brackets to look up the target item

# Step 3: Print the extracted item
print("Extracted Nested Value:", target_value)
    HOW PYTHON WORKS EXPLANATION: • Line target_value = nested_data[1][0]: To read items out of nested tuples, you must chain multiple sets of square brackets [] together. • The first index [1] tells Python to select the second sub-tuple ((3, 4)). The second index [0] then targets the very first item inside that specific sub-tuple, which successfully retrieves the integer 3.

def analyze_sequence(numbers_tuple):

print("Min:", low, "| Max:", high, "| Total Sum:", total)
    HOW PYTHON WORKS EXPLANATION: • Line return min(numbers_tuple), max(numbers_tuple), sum(numbers_tuple): A Python function can technically only return exactly one single object. • When you list multiple comma-separated items in a return statement, Python automatically packs them into a single tuple behind the scenes. The calling code on Line low, high, total = ... then unpacks that tuple directly into your independent local variables.

    print("Student Name:", name, "| Exam Grade:", score)
    HOW PYTHON WORKS EXPLANATION: • Line for name, score in grades.items():-The dictionary method .items() generates a sequence of two-element key-value tuples during loop execution. • Instead of forcing you to extract items manually by index, Python automatically unpacks each key-value pair directly into your loop variables name and score at the start of every iteration.

    Q20. Write a script that uses a match-case statement to check the tuple variable status = (404, "Not Found") and print a custom message based on its contents.

    # Step 1: Define a state tracking tuple record
status = (404, "Not Found")

# Step 2: Route the execution path using match-case structural comparison
match status:
    case (200, message):
        print(f"Success Content: {message}")
    case (404, message):
        # Step 3: Print the message when the exact pattern triggers
        print(f"Handled Error Message: {message}")
    HOW PYTHON WORKS EXPLANATION: • Line match status: and case (404, message):- In modern Python, the match-case statement inspects both the structure and values of a tuple simultaneously. • The engine verifies that the data is a two-element tuple, checks if the first item matches the literal number 404, and then automatically extracts the second item, binding it instantly to the local variable message.
